# Contributing

Thank you for helping FrameVault become useful to creators.

Use Node.js 24 or later. Start with `npm start`, then run `npm run check` and `npm test`. There is no dependency installation step.

For a bug, include the version, OS, Node version, reproduction steps, expected/actual result and redacted logs. Use synthetic examples rather than private artwork or API keys.

For a feature, describe the creator's problem and the smallest useful workflow. Discuss database migrations and privacy boundaries before implementation.

Keep pull requests focused. Include meaningful tests for changed behavior and update documentation when necessary. Screenshots help with interface changes. Describe whether AI validation used a mock or a real provider.

Code and original demo artwork use the MIT license. Do not submit assets you do not have permission to redistribute.
